# homebrew-tap

Homebrew formulae for [RSafargalin](https://github.com/RSafargalin)'s tools.

```bash
brew tap RSafargalin/tap
```

## Formulae

| Formula | Description |
|---|---|
| [`sextant`](https://github.com/RSafargalin/sextant) | Code intelligence for Swift projects: repository map, structural search, semantics. CLI + MCP server. |

```bash
brew install sextant
```

Formulae here are copies; the source of truth for each lives in its own repository and is
updated as part of that project's release process.
